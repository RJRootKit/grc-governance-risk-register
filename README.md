# GRC Portfolio

Five practical GRC projects by Gobl3t: information security, insurance and financial services, Kenya.

| Repo | Focus |
|---|---|
| grc-governance-risk-register | Governance framework and risk register |
| soc2-audit-tracker-cloud-mapping | Audit tracker and SOC 2 cloud control mapping |
| vapt-threat-intel-dashboard | Vulnerability assessment, pentest templates, threat-informed prioritisation |
| vendor-risk-assessment-program | Third-party risk and DPA 2019 checks |
| cis-ad-security-assessment | CIS/STIG and Active Directory assessment |

Each folder is a standalone repo. All data is sample data.
