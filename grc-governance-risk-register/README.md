# GRC Governance Framework & Risk Register

A reusable ISMS governance structure and scored risk register aligned to **ISO 27001:2022**, **NIST CSF** and the **Kenya Data Protection Act 2019**, written for insurance and financial services.

> All data in this repo is **sample data**. No client information is included.

## Contents
| Path | Purpose |
|---|---|
| `docs/governance-structure.md` | Policy hierarchy, roles, RACI, review cadence |
| `docs/risk-methodology.md` | 5x5 scoring, risk appetite, treatment options |
| `templates/risk-register.csv` | Register template with sample rows |

## How to use
1. Set risk appetite in `docs/risk-methodology.md` before scoring anything.
2. Copy `templates/risk-register.csv` and replace the sample rows.
3. Review quarterly; report the top risks to the board.
