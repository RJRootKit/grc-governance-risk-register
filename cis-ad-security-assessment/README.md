# CIS Benchmark & Active Directory Security Assessment

A repeatable method for auditing Windows Server against **CIS / STIG** baselines and reviewing **Active Directory** design.

> No client or hostname data is included. Run assessments only with written authorisation.

## Contents
| Path | Purpose |
|---|---|
| `docs/ad-review-checklist.md` | AD design and hygiene checks |
| `docs/cis-audit-method.md` | How to run and score a CIS/STIG audit |
| `templates/findings-register.csv` | Findings with fix and rollback note |

## Useful tools
[PingCastle](https://github.com/netwrix/pingcastle) (health check; check its licence terms) and [BloodHound](https://github.com/SpecterOps/BloodHound) (attack paths).
