# Lessons Learnt

- **Map controls once, reuse everywhere.** A single control set cross-referenced to SOC 2 and ISO 27001 avoids duplicate work.
- **Evidence collection, not control design, is where audits stall.** Name an evidence owner per control from day one.
- **Shared responsibility must be explicit.** For each control, record what the cloud provider covers and what you cover.
- **Overdue findings need visibility.** Review the tracker weekly with owners.
