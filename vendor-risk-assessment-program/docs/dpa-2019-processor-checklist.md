# Data Processor Checklist (Kenya DPA 2019)

- [ ] Written contract defining processing purpose, duration and data types
- [ ] Processor acts only on documented instructions
- [ ] Confidentiality obligations on processor staff
- [ ] Appropriate technical and organisational security measures
- [ ] Sub-processing only with prior authorisation
- [ ] Breach notification to controller within agreed timeline
- [ ] Assistance with data subject requests
- [ ] Cross-border transfer safeguards confirmed
- [ ] Return or deletion of data at contract end
- [ ] Processor registration with the ODPC verified where required

Confirm current requirements against the Act and ODPC guidance before relying on this list.
